## How to Run It Locally

If you want to run the website on your computer, first clone the repository:

```bash
git clone https://github.com/zemaldars01-png/zemal-personal-site.git
```

Then open the project folder:

```bash
cd zemal-personal-site
```

After that, open `index.html` in your browser.

You can also use a simple local server if you want:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

No packages or extra dependencies are required.

## How It Works

The website is mainly built with HTML and CSS.

HTML is used to create the different sections of the website, including the navigation bar, projects, achievements, leadership, certificates, and contact section.

CSS is used to control the colors, spacing, card layout, buttons, image sizes, and responsive design.

I used Flexbox for some parts of the layout, such as the navigation bar and hero section.

I used CSS Grid for the project cards, achievement cards, and certificate gallery.

I also used media queries so the layout works better on smaller screens such as tablets and phones.

JavaScript is only used for a small back-to-top feature. When the user scrolls down the page, the button appears. When it is clicked, the page scrolls back to the top.
